03 / Projects

Privileged access tools I built myself

Both projects take a core PAM idea and implement it end to end in Java.

JIT Access Provider

View on GitHub

Just-in-time SSH access to Linux servers. Users get a temporary OS account when they need one and lose it when the window closes, so no standing credentials are left behind.

  • Time-bound access reduces the attack surface by about 90% compared with standing accounts.
  • Role-based access control with Spring Security across 10+ secured endpoints.
  • Temporary users are provisioned and revoked over SSH (JSch) by a 60-second scheduler.
  • A normalized MySQL schema keeps a full audit trail of every session: grant time, expiry and revocation status.
  • Java
  • Spring Boot
  • Spring Security
  • Spring Data JPA
  • Hibernate
  • MySQL
  • JSch
  • Maven

KeyMatrix

View on GitHub

A desktop credential vault in JavaFX. It stores 100+ credentials with nothing in plaintext at rest.

  • AES-256 encryption with PBKDF2 key derivation.
  • Full credential lifecycle with search and filter, cutting average retrieval time by about 40%.
  • Shipped as a Windows MSI installer with a bundled Java runtime.
  • Java
  • JavaFX
  • AES-256
  • PBKDF2
  • MSI
