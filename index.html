JIT Access Provider

View on GitHub

Just-in-time SSH access to Linux servers. Users get a temporary OS account when they need one and lose it when the window closes, so no standing credentials are left behind.

  • Role-based access control with Spring Security across 10+ secured endpoints.
  • Temporary users are provisioned and revoked over SSH by a 60-second scheduler.
  • A MySQL audit trail records every session: grant time, expiry and revocation status.
  • Java
  • Spring Boot
  • Spring Security
  • MySQL
  • JSch

KeyMatrix

View on GitHub

A desktop credential vault in JavaFX with nothing stored in plaintext at rest.

  • AES-256 encryption with PBKDF2 key derivation.
  • Full credential lifecycle with search and filter.
  • Shipped as a Windows MSI installer with a bundled Java runtime.
