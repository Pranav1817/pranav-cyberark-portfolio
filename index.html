// field notes

Things I actually fixed

Short accounts of real work in the lab — the problem, what I did, and where it landed.

VAULT · LDAP

Killing the self-signed cert

Problem Directory binding rode on a self-signed LDAP certificate — untrusted, and a red flag in any hardened deployment.

Action Generated the request, obtained a CA-signed certificate, and swapped it into the LDAPS configuration cleanly.

Result A trusted, warning-free directory connection the vault could authenticate against with confidence.

AUTH · 2FA

Two factors, no compromise

Problem Privileged logins backed by a single factor are the softest target in the whole chain.

Action Layered PKI-based two-factor authentication on top of LDAPS so identity is proven by certificate and directory.

Result Stronger assurance on every privileged sign-in, with no extra friction on the legitimate path.

PSM · SESSIONS

The session that wouldn't let go

Problem PSM sessions froze mid-connection and had to be terminated and reconnected — recurring after a set period, the kind of intermittent fault that hides from a quick look.

Action Traced the behaviour across the session path, isolating where it stalls rather than guessing — the slow, methodical part of the job.

Result An ongoing diagnosis that sharpened how I read PSM connection faults and where they originate.
